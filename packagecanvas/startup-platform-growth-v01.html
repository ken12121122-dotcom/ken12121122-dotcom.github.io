KNOWLEDGE WORLD · PLATFORM GROWTH

從個人技能書，
成長為多人知識平台。

一個人走過的研究與工作路徑，能否轉換成另一個人可搜尋、可使用、可授權改造的能力？

策略研究 v0.1未核准／非法律意見資料基準 2026-10-13

EXECUTIVE DECISION

先證明技能可重用，再擴展成多人世界。

現在：個人工作台

找書、召喚書、定位功能、執行並驗證結果。

下一步：雙人共享

A 建書、B 授權借閱與 Fork、保留血緣及版本。

中期：創作者生態

團隊空間、權限管理、可重複交付的技能與服務。

遠期：多人 Knowledge World

世界、角色、社交、市集和多人合作的遊戲化入口。

產品核心：Book Protocol 是資料與能力契約；3D 圖書館只是其中一種前台投影。

↓
4. 多人知識世界社交、探索、共同建造與玩家間交流

SYSTEM ARCHITECTURE

Web-first · Protocol-first · API-first

Web / PWA / Android / iOS / World UI固定圖書館、漂浮書本、語音、搜尋、地圖
↓
Book Registry + Command Registry + Source Manifest身分、版本、來源、技能與權限對應
↓
Identity / Storage / Search / Execution Gateway身分驗證、資料儲存、檢索、可回退命令執行
↓
外部工具、使用者資料源、可替換 AI 引擎每個連接器都需要使用者授權

GitHub 維護程式碼與版本，不承擔正式平台的私人資料庫。Book ID 與外觀分離；書的 Fork 不複製私人憑證或原作者執行權限。

CREATOR RIGHTS

可借閱，不代表可任意販售或執行

內容權利

作者、出處、授權範圍、改作與再分享條件。

程式與工具授權

執行碼與開源依賴是否可商用、修改、再散布。

外部存取權

帳號、API 金鑰和私人資料不能跟著書自動轉移。

治理與申訴

隱私、侵權舉報、下架與團隊管理權限。

MARKET VALIDATION

衡量成功任務，不只數書本。

候選北極星指標：每週成功重複使用的技能書任務次數。
指標測量內容資料狀態
首次任務成功率新使用者是否完成真實任務待測試
跨人重用成功率B 是否成功使用 A 建立的書待測試
週活躍工作使用者是否反覆回來完成工作待蒐集
付費意願與單位成本收入是否可覆蓋成功任務成本待驗證

候選封閉測試：10–20 人、5–10 本技能書、追蹤四週。為試驗設計，不代表市場統計。

FINANCING

先清楚資金用途，再決定募資。

原型期

自有資金、現有工具。降低現金消耗，驗證閉環。

產品化期

評估 SBIR 研發補助或合適的天使投資，須確認資格和真實研發成果。

平台擴張期

以留存、付費需求、成本結構與可移轉技術資產爭取資金。

退出選項

持續經營、授權、資產交易或股權出售；融資契約可能影響未來退出權利。

貸款有還款義務，不宜只因擔心競爭者就舉債。官方條件須以申請時的最新公告為準。

STAGED DELIVERY

18 個月候選路線與 Gate

期間交付物進入下一階段前的證據
0–3 個月IP 來源盤點、單人書本任務閉環可實際完成、有版本與權限紀錄
3–6 個月雙人共享與 Fork PoC跨人使用成功、不外洩權限
6–12 個月封閉團隊版、帳號與同步使用者持續使用、成本可控
12–18 個月市集／企業／多人世界方向評估實際需求與資金用途支持決策
不得把候選里程碑當成已承諾日期。維持現有工作與生活安全邊界，避免為創業進度犧牲必要休息。

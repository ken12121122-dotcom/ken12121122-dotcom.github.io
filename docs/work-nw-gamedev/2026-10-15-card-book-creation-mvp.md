# WORK-NW-GAMEDEV-001｜創造術先行：卡片與書本 3D 進入世界 v0.1
日期：2026-10-15
狀態：CANDIDATE／手機 WebGL2 操作驗收待完成；非正式發布。

## OWNER 本次決策
先不開發整套符文書／法術書／手勢書，也先不實作 AI 賦予功能。將前期入口簡化為兩種內建安全創造術：
- **卡片創造術**：創造有唯一 ID 的空白卡；初始沒有技能、授權或專屬書籍，先以真實可點擊的 3D 卡片懸浮在人物附近。點擊卡片進入近距離專注模式，編輯與退出不破壞卡片身分。
- **書本創造術**：創造有唯一 ID 的空白書；使用既有 3D 書本模型與環繞軌道加入世界，書名與空白卡槽以共同物件契約記錄，保留現有一般書及其閱讀器。此版本書頁模式沿用 LEGACY；真正的雙頁書動畫另行驗證。

下一階段將測試：**從人物身旁懸浮卡 → 選取玩家新製的書 → 放入該書的空白卡槽 → 取回卡 → 重開遊戲確認同一 Card ID 不變**。本輪只交付創卡／製書與場景物件整合，不把後續放卡當作已實作。

## 共同物件契約
儲存在 `living-library-player-objects-v1`，與 `living-library-workbench-v1`（書庫顯示偏好）分開。建立卡與書共用 `id,objectType,templateId,status,revision,createdAt,updatedAt`。用瀏覽器安全隨機來源產生 `local.card.*`、`local.book.*` ID。卡片保留 `ability:null`、`permissions:[]`、`ownerBookId:null`、`placement:hover`；書本保留 `contentIds:[]` 和 `active` 環繞／書架狀態。

透過卡片創造術修改卡名、說明時不能以輸入資料注入腳本或賦予未經登記技能。未知資料格式不得覆寫原本的本機存檔。創作保存僅在同一網站來源的當前瀏覽器／WebView，**無跨裝置雲端同步、也非備份**。清除站台資料可能遺失草稿。

## 與正式書庫分離
在既有《遊戲之書》卡冊**附加**兩個公開功能入口，保留原有 GBA、Vault、遊戲設計卡。創作物件與正式 GEN2 投影的 ID、權限及資料來源分離。卡片未放入任何書時，不被偽裝成原有公開書的卡片槽成員。新書作為本機書籍額外附加於 `BOOKS`，透過既有 `bookMesh`、`rebuild`、`updateOrbit` 實際放進 3D 場景；GEN2 登入／斷線重新投影後仍重載本機書。

本機空白卡使用 3D Plane/Box Mesh + CanvasTexture，懸浮位置隨角色平移；與既有環繞書是不同物件。點卡後由 3D 相機靠近同一張卡，禁用觸控視角干擾；可點圖示編輯或退出，保留原場景／相機姿態。當 WebGL 不可用時仍可由《遊戲之書》以 2D 創造術網頁查閱／編輯本機草稿，不能虛報已驗證手機 3D。

## 分段驗收
1. 模組契約：本機創卡與製書 ID 不同、卡片懸浮且沒有歸屬書、無授權能力；改名不換 ID；書有空卡列表。
2. 網頁入口：兩創造術在現有《遊戲之書》，所有原有功能卡及既有一般書入口未丟失。
3. 3D 交付：建立卡後關閉書頁能在人物附近看到卡片；點它鏡頭進入專注視角、返回後仍懸浮；創書後新增書在人物外圍環繞；書架、人物相機及自由移動沒有退化。
4. 保存驗收：重新整理／更新連結／退出重新開啟之後，卡書保持同一 ID 與位置狀態，其他私有資料與 ROM/GBA 存檔不被重設。
5. 實機驗收：Android WebView 實際手勢命中與圖像穩定度必須由 OWNER 回報才標 PASS；雲端授權與同步不在本輪。

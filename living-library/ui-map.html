③ 重疊功能如何管理

  • 一張卡片可以被多本書引用，但 Card ID 不變，例如 public.canvas.workbench「知識工作台」。跨書引用不是複製功能。
  • 更改共用卡片名稱／URL 之前，必須先列出所有引用書籍；不能只因卡片在某一本書裡就假設修改是局部的。
  • 「系統之書」管 Web UI 名詞與圖書館維護索引，「安卓之書」管原生功能與更新，「遊戲之書」管遊戲內容。
  • 本頁只讀取公開功能目錄，不包含 Token、私有 GEN2 正本或原生執行操作。

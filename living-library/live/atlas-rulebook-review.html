RULE / 01
已討論共識

唯一圖鑑與正式身分

  • 念動世界只有一個正式的萬物圖鑑登錄身分，不能複製。
  • 圖鑑可持續增加頁數，既有編號和永久位置不變。
  • 圖鑑編號應獨立存在；ATLAS-0001 目前僅為提議格式。
  • 正式每張卡代表一個唯一世界實體，不得複製或重新發號。
RULE / 02
已討論共識

唯一 0 號格與永久卡槽

  • 0 號是整本圖鑑唯一暫存與 GBA 讀卡格；最多一張，可容納任何合法卡片類型。
  • 001–009 是首頁左頁永久格；以後每一展開左右各九格。
  • 永久編號對應唯一卡槽；不允許其他編號佔用。
  • 從永久格搬到 0 號，不改變所屬的永久登錄位置。
RULE / 03
已討論共識

普通卡 → 永久唯一卡

  • 普通卡可放進 0 號格提出升級申請。
  • 核查原卡 ID、候選世界物件、唯一綁定和場景錨點，由 AI 審核、你核准後正式登錄。
  • 完成綁定時才配發不可重複的正式流水編號；卡片 ID 沿用、不另製新卡。
  • 升級不可逆。升級後所有普通編輯與刪除入口失效。
RULE / 04
已討論共識

物件與卡片絕對互斥

  • 一個永久實體只有一份權威登錄資料。
  • 世界有實體，就沒有實體卡片；有實體卡片，世界就沒有該實體。
  • 轉換中不可重複生成；中斷或同步衝突時應停止或回復一致狀態。
  • 任何時候都不能透過匯入、備份或舊版編輯器繞過唯一性。
RULE / 05
已討論共識

點擊、長按與原位還原

  • 短按法陣開啟卡片資訊；長按滿 3 秒，進度圓圈到 100% 才卡片化。
  • 轉換動畫沿用卡片召喚風格；拖動、離開、取消或失焦須中止進度。
  • 實體化必須校驗原始場景、位置、旋轉與縮放。
  • 找不到可信錨點就不實體化，不任意出現在玩家旁。
RULE / 06
已討論共識 · 按鍵待整合

GBA、翻頁與快速定位

  • 任何展開皆有 GBA 導航書籤，能立即返回 GBA 首頁。
  • GBA 提供所有登錄編號的狀態檢視、上下移動頁面游標、按確認鍵翻到指定頁。
  • 手動翻頁和 GBA 精準定位共用同一份資料。
  • 搜尋、查看和定位不觸發移卡、重新編號、實體化或任何修改。
RULE / 07
已討論共識

受控修改（不可自行解鎖）

  • L2 永久卡在任何普通界面均為唯讀；放到 0 號 GBA 也不自動解鎖。
  • 申請變更 → AI 對照審查 → 你核准 → 僅變更獲准欄位 → 記錄修訂。
  • 唯一 ID、編號、永久位置與原始錨點使用更嚴格的核准與一致性檢查。
  • 修改授權不可拿去編輯另一張卡、另一個欄位或另一個版本。
RULE / 08
技術必要約束

權威資料與交易一致性

  • GBA、卡片簿和世界模型是同一權威紀錄的不同投影。
  • 真正的絕對唯一需後端或可信同步機制統一寫入；手機 localStorage 與一般 GitHub 備份不能單獨保證跨設備唯一。
  • 升級認證、歸檔、變形、變更都需帶版本檢查與失敗回復。
  • GitHub 上傳回報成功不等於 AI 已批准認證或已正式納入系統之書。

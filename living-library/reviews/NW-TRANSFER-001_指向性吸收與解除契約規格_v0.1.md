# NW-TRANSFER-001｜指向性轉移與具現化核心 v0.1（候選，不是已核准正式規則）

> 範圍：念動圖書館 3D 場景中的**來源物件 → 目標物件**轉移；本版重用於「解除綁定術」實驗，保留地面法陣既有締結流程，不修改 GEN2、GBA、Android。

## 1. 使用者敘述的區別
- 初始法陣：世界原點的**地面 3D 法陣**（`local.rune.origin`），不會移動。
- 初代法陣卡：使用者製作的**原始卡片**（真實 `local.card.*` ID）。解除綁定卡的最終目的地是**這張卡片表面**，不是地面法陣。
- 解除綁定術卡：使用者自行製作的另一張普通卡；施放後進入**收納／已消耗**狀態，不能當成刪除或回收。

## 2. 統一介面與階段

```
卡片/物件來源 ID (sourceId)
      │
      ├── 3 秒持續長按／完整圓形光環
      │
      ├── 候選搜尋（身份 + 有效狀態 + 3D 距離）
      │
      ├── Source world position + Target world position
      │       └── 能量連線／游動粒子／目標光環
      │
      ├── 明確確認（取消 = 0 次資料寫入）
      │
      ├── DirectedTransfer.sample (飛行 + 弧線 + 縮小)
      │       ├── world target = card front
      │       ├── world target = rune surface
      │       └── world target = book/building anchor (未開放)
      │
      └── 只有 animation.done 才進行原子狀態交易
              ├── 解除契約（目標原卡）
              └── 消耗術卡， containment.holderId=目標原卡 ID
```

- 遊戲中的飛行**不可依賴固定鏡頭座標、卡名或地面原點**；逐幀取得目標世界座標。模型的當前 ID 永不替換成展示編號。
- `directed-transfer.js` 的 `normalize()/sample()` 是獨立於 Three.js 的純數學模組。動畫與資料寫入分開，不作自動網路呼叫，也不帶權限。
- `object-craft.js` 的 `unbindAndAbsorbSpell` 在**同一 localStorage JSON 寫入**中完成「解除目標契約 + 術卡收納」。它先檢查雙方 ID/ revision / 狀態和唯一法陣關係。
- 施法途中退出、跳轉、觸控取消或失去來源時**不應改動資料**。在真正收到新的同步資料前，不顯示「已消耗」為永久狀態。
- `containment: {kind:'consumed_spell',holderId:'local.card.*',holderType:'card',state:'stored',absorbedAt:'...'}` 明確記錄收納位置，不使用 `recycled` 或刪除。
- 已消耗術卡從漂浮卡群隱藏、不能放進卡冊、編輯或一般回收；真正的再次召喚必須使用**未來另行核准的召喚術**，取回同一 `id`，不得無條件重生新卡。

## 3. 本次實作範圍（Draft PR #258）
- 玩家已有名字符合明確白名單的「解除綁定」術卡才可施法；玩家不用新建第二張測試卡，不自行改照片或卡號。
- 與地面法陣相同的持續 **3 秒 / 192 段幾何畫圓進度**，可移動角度、動畫取消規則相同。
- 距離搜尋目前限制為術卡附近 3.6 世界單位、只選 `bound` 或 `cardified` 且仍漂浮的**唯一**初始法陣契約卡，且兩個太近時拒絕猜測。
- 明確顯示聯繫，詢問是否解除。確認後定向飛行入**目標卡片**，成功後原卡解除契約並繼續漂浮；術卡進入收納。
- 不新增另一個萬物圖鑑、實體卡 ID、永久編號、GBA 送審功能。

## 4. 新增 RUNE-04 與 RUNE-05 同源卡片閉環（仍為 Draft PR #258）

1. **RUNE-04 直接吸入**：首次長按地面初始法陣 3 秒，選中鄰近普通原卡，確認後使用 `DirectedTransfer.sample` 將**原卡模型**縮小並飛入地面法陣。動畫未結束不寫入；完成後 `sealRuneCard` 單次寫入 `runeBinding.state='sealed'`、`placement='contained'`、`containment.holderId='local.rune.origin'`，原卡 ID、圖片、書面資訊不變。
2. **既有舊版 bound 卡補封印**：在同一裝置已先用舊版連結、尚未吸收的原卡，可以再次長按地面法陣，確認後**補完封印動畫**；若原卡在右側 GBA，須先取出，避免誤移。
3. **RUNE-05 第二次長按**：當原卡已 `sealed` 且隱藏於地面法陣，再次長按 3 秒，顯示「是否將初始法陣變成卡片」。確認後，同一原卡逆向飛出，`materializeRuneCard` 將其改為 `placement='hover'` / `runeBinding.state='cardified'`，**不造新 ID**；地面法陣從場景收起，之後能操作該卡及放入萬物圖鑑右側 GBA。
4. **解除綁定術後續**：3 秒長按「解除綁定」術卡，對 `cardified` 目標進行能量連線並徵求同意，術卡飛入這張實體卡。僅在動畫完成時一次寫入 `unbindAndAbsorbSpell`，原卡解除綁定，術卡 `placement='contained'`、`containment.holderId=targetCardId`，地面法陣重新顯現且可再契約。
5. **取消／中斷**：若取消對話框、失去頁面可見性、版本改變、儲存失敗，沒有原卡刪除或消耗；已經寫入的舊 `bound` 狀態仍可經原來還原頁復原，封印和卡片化狀態則不可任意重置。

## 5. 仍未實現、不可誤報通過

- **消耗術卡的重新召喚**：保存了原卡及 `holderId` 但尚無通用 `release` 交易、施法入口、權限與視覺逆向召喚。
- **L2 升級**：萬物圖鑑右側 GBA 讀卡格保留，但放入 `cardified` 不等於核准 L2，沒有永久編號、Github 正式升級的隱性自動執行。
- **任意類型目標**：轉移核心可以採用目標的世界座標，但非所有書本與建築物都已支援交互感測或存檔容器。
- **真實手機 WebGL／完整操作鏈**：Node 和 CI 瀏覽器導航測試並非 OWNER 裝置的 3D GPU 閉環；實機驗收前維持 Draft PR，不改正式 `main` 和正式版本戳。

## 6. 後續驗收建議

- 空白普通卡 → 3 秒長按地面法陣 → 確認 → **卡沒入地面法陣** → 重啟依然藏在地面法陣（ID 不變）。
- 再次長按同一法陣 3 秒 → 確認 → **原卡飛出** → 地面法陣隱藏。
- 將「解除綁定術」卡靠近具現化原卡 → 長按 3 秒 → 取消時兩卡完全不變；確認後術卡**沒入原卡卡面（非地面法陣）** → 重啟後術卡不再漂浮，但原始資料仍存，原卡變普通卡。
- 再次締約與 GBA 右側讀卡格；核對最終沒有任何新卡 ID、圖片丟失、法陣連結重複或未知產生的 L2。


## 7. OWNER 2026-10-17 核准的實際閉環（RUNE-06 與永久資格鎖）

**首次締結（卡 → 地面初始法陣）**：
- 世界中的「初代法陣卡」靠近原點法陣；玩家長按**地面法陣** 3 秒，確認連結，**原卡模型飛行、縮小、沒入地面法陣物件**。
- 持久化後原卡 `placement:'contained'`、`runeBinding.state='sealed'`，不在漂浮環，原卡 ID、圖片與書面內容不變。
- 舊版已印上 `bound` 但未封印的卡可以完成此段封印；不重複建立第二張法陣卡。

**形態切換（地面法陣 ⇄ 原卡）**：
- 地面法陣已封印時，長按**法陣** 3 秒 → 確認 → 同一原卡從地面飛出具現化，`state='cardified'`；地面法陣模型收起。
- 原卡在漂浮世界中（不在書內）時，長按**原卡** 3 秒 → 確認 → 同一張卡飛回地面法陣，`returnRuneCard` 將狀態回到 `sealed`、保留原契約。
- 此循環只切換形態，絕不執行解除契約或產生新身份；降低動態效果時縮短動畫。

**解除契約（施法卡 → 目標原卡）**：
- 先將地面法陣具現化為**原卡**。將玩家創造的「解除契約卡」／「解除綁定術」拖到世界中；長按**法術卡** 3 秒，對附近符合條件的原卡進行光線連結與明確確認。
- 確認後**法術卡模型**沿指向性路徑縮小，沒入**具現化原卡卡面**，不是地面法陣。動畫結束後 `unbindAndAbsorbSpell` 一筆寫入：解除原卡的 `runeBinding`；法術卡 `placement='contained'`，`containment.holderId=目標原卡 ID`。法術卡從漂浮世界消失，但保留原始 ID 和影像。
- 同一「解除契約卡」卡面格式可在 GBA「卡片下載」選單從已建立且合格的格式列表選取；一張**新空白卡**在右側唯一 GBA 讀卡格被寫成新**獨立 ID** 的法術卡，拖出後可再次施法。已消耗的舊原卡仍封存在 holder 裡，不會被召喚或復活。整個循環可重複，但有本機目前 64 有效卡片上限。

**永久編號鎖（升級後不可解除）**：
- 未來通過正式升級／認證的永久編號卡，`isPermanentRuneCard` 判斷受保護身份，`unbindAndAbsorbSpell` 在唯一原子寫入前拒絕，法術卡不被消耗；目標搜尋也跳過永久目標。
- `restoreUncommittedRuneCard` 舊還原入口也拒絕已升級者；GBA 下載／左頁舊實驗複製不可藉此複製永久身份。
- 玩家自行輸入的 `cardNumber` **不是永久編號**，不影響普通卡解除契約。**本階段不新增任何永久編號、升級認證或登錄功能**。
- 永久法陣卡是否仍能切換「卡 ⇄ 地面法陣」與能否解除契約是兩個概念：當前允許**只切換形態**，不允許永久契約解除。

**驗收重點**：需要確認整個 3D 多次施法／儲存／回載，觸控長按不觸發一般卡片編輯，失敗不吞卡；Node／CI 成功不等於 OWNER 手機 WebGL 驗收。PR #258 仍為 Draft，未合併 main。

## 8. RUNE-07｜解除契約後的法陣能量返回原點（OWNER 2026-10-17 已核准）

**採用確定的雙階段世界動畫，而不是讓地面法陣突然切換可見：**

1. 玩家長按「解除契約卡」3 秒並確認施法。法術卡沿 `DirectedTransfer` 飛向「初代法陣卡」，縮小、沒入目標卡片。
2. 上述第一階段**成功完成**後，才執行原有 `unbindAndAbsorbSpell` **單筆原子持久化交易**：原卡解除契約，施法卡保存成 `consumed_spell` 並從世界消失。**持久化失敗則不得播放返回法陣的特效，也不修改任何卡片或法陣狀態。**
3. 持久化成功後，「初代法陣卡」保留在漂浮世界中，從其實際 3D 世界座標放射光環，並且有一顆能量光球沿指向性光束向世界固定原點 `local.rune.origin` 的表面飛行。
4. 能量抵達原點前的最後約 30% 進度，**原本同一個地面法陣模型**從原點縮放展開，恢復完整法陣；不得建立第二個 3D 法陣物件，也不得把卡片搬回地面。
5. 正常動畫長約 1450 ms；降低動態效果模式縮短至約 340 ms。途中頁面失去焦點／隱藏／離開時，立即完成**視覺收尾**、還原法陣可見與模型原比例，不再次寫入儲存、不吞卡、不重複解除契約。
6. 後續仍可將已解除的普通初代法陣卡重新綁回地面法陣；升級成真正的永久編號／已認證法陣卡，則**不可解除契約**。填寫普通卡 `cardNumber` 不等於永久卡。

此階段只升級「解除成功後的法陣回歸特效」，不啟用永久卡登錄、價格、商店支付，也不調整卡冊左頁九格／GBA 格式下載的既定分工。

**實測 Gate**：Node 自動化與既有 Three.js 瀏覽器回歸應通過；手機 WebGL 長按、動畫跨階段與回載一致性仍需 OWNER 驗收。正式 main 及 Pages 未經額外發布核准不得自動修改。

## 9. 2026-10-20 OWNER 規則覆寫｜術卡單次消耗，不保存歷史術卡

> **本節優先於上文 2026-10-17 的「法術卡保留在 holder／可從歷史下載／等待逆向召喚」設計。**這是對既有 v0.1 規格的明確修訂，不得把舊段落當成當前遊戲規則。

- **唯一施法觸發**：玩家長按合法的「解除契約／解除綁定」法術卡 **3 秒**，若目標唯一、有效且未永久認證，立即在**單筆原子寫入**中解除原卡契約並**直接從玩家物件儲存陣列刪除施法卡紀錄**。無第二次「是否解除」詢問。失敗或曖昧目標一律不改寫、不吞卡。
- **絕不保留已消耗術卡**：不得留下 `consumed_spell`、`consumedBy`、holder 收納卡、逆向召喚清單、卡片歷史或 GBA 歷史範本。動畫只是交易後的視覺效果，失去焦點不回復術卡、不重複提交。
- **舊紀錄清理**：僅對嚴格符合舊版 `consumed_spell` 記號、且不含其他活契約／永久卡的舊術卡清理；原卡、其他書籍與卡片保持不變。不任意清空整個本機儲存。
- **世界與書內現存的可複製卡**：只有仍實際存在、且使用者明確勾選 `downloadTemplate:true` 的合法普通卡可列為 GBA 模板。已消耗卡不具可下載歷史身分。若需要連續使用解除法術，須在施放前先從合格可複製的原卡下載新物理卡；這不代表保留消耗後歷史。
- **原始媒介再利用**：普通空白卡締結的掃描群組經解除法術成功後，原卡保持原 ID 並恢復成經 `isBlankCopyMedium` 驗證可放入 GBA 的**真正空白卡**；不製造複本。普通自訂神器／法陣卡僅解除契約、保留自己的卡面資料，不強制變空白。
- **形態≠契約**：掃描卡或已綁定世界物件的長按只切換整組 `card` ⇄ `world`，絕不直接執行 `B.release()`。解除與收納要保持職責分離。
- **唯一／永久卡不解除**；儲存資料衝突時不做半套解除。

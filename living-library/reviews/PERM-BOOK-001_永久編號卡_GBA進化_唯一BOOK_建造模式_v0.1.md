# PERM-BOOK-001｜永久編號卡 × GBA 認證 × 唯一 BOOK × 建造模式
2026-10-17｜OWNER 全部同意之候選實作，尚未正式發布；PR #259

## 核心絕對制約
1. **同一原卡身分**：普通原卡先透過初代法陣完成有效締結、卡化；永久登錄不能新建第二個卡 ID。卡面文字、圖片與人物自行創作內容完整保留，升級只增加金色框、唯一編號與不可逆身分。
2. **GBA 不得直接操作世界實體**：GBA 從 BOOK 的永久格調出的是**真正的原始卡片**，放到其唯一 0 號讀卡格；之後必須把卡片本身從 GBA 拖出／取出世界，長按原卡 3 秒才啟動投影、選定位置、確認卡 → 世界實體。世界實體要回 BOOK 必須先變回原卡、插入 GBA，再歸入專屬永久格。不得設計 GBA 直接吸收地面法陣或直接在世界召喚法陣。
3. **唯一 BOOK**：唯一正式管理本是 `local.atlas.compendium`；本機普通《卡片之書》與自行創作的 `local.book.*` 卡片之書不能收納永久編號卡。GBA 唯一 0 格映射程式內 `slotIndex=9`，不是永久地址。
4. **專屬編號固定地址**：BOOK 首頁左 001–009 是自己的永久固定位置，首頁右側 GBA＋0；後續每展開左右各九格、永不換號（後續 010–027、028–045……）仍需物理翻頁模組，本 PR 的可操作第一階段**只處理 001–009**，不以一般卡冊中的 18 格冒充永久頁。BOOK 格位對身份永久保留；原卡暫存在 GBA、世界漂浮、世界實體時不產生第二個可操作原卡。
5. **永久限制**：一旦本機完成升級，普通解除契約卡、舊解除入口、卡片格式下載／實驗複製、普通卡片編輯／修改圖片／回收操作全部禁止。永久卡仍可在世界移動，修改「世界物件位置」不解除永久契約、不影響 BOOK 身分和卡片插圖。更高等級正式內容變更流程另行設計。
6. **兩種移動入口共用投影**：
  - **從原卡長按三秒** → 投影先出現在自己記錄的世界錨點 → 可點擊地面任意有效位置、左搖桿細移、右半畫面自由旋轉視角、網格吸附／轉向十五度 → 確認後唯一原卡縮入投影並轉成該位置的法陣實體。取消不變資料。
  - **世界建造模式** → 自動識別已實體化的永久法陣 → 顯示同一半透明投影 → 同一套定位／吸附／旋轉 → 確認後原世界法陣移動並記錄新位置。投影綠＝可放、紅＝不可放；不新增第二個法陣的持久記錄。
7. **位置與轉換**：`permanentRegistry.anchor` 存最後確認的 `sceneId/position/rotationY/scale`，卡 ↔ 法陣切換保存最新位置。初代法陣普通卡在未永久升級前仍保持既有地面原點，不能擅自改舊流程。
8. **進化畫面**：GBA 身分＋契約＋唯一性＋空槽檢查 → 明示限制 → 玩家按住實體 GBA 內嵌認證對話按鍵 ✦ 滿三秒 → 卡在讀卡槽發光、GBA 螢幕顯示進化進度 → 原卡金框／編號浮現，正式存入 BOOK 的 001 等永久格。動態偏好設定會縮短動畫。
9. **權威性精確標示**：本機 WebView/瀏覽器 localStorage 並沒有權威跨設備唯一配號，沒有真正的 AI 審查決策。現有 GBA 確定性的檢查只能標示為「本機正式登錄試行」，不可把 GitHub 備份、使用者輸入的 `cardNumber` 或程序自己判斷冒充已完成 AI 審核／全裝置正式 L2 認證。後續要設計可信遠端身份與審批事件帳本，加入跨裝置衝突及重播防護，再審慎決定啟用真正 L2 / 全球唯一編號。

## 既有系統保留
- 維持第 0 號 GBA 讀卡格的獨立卡片格式下載；普通可下載格式不從左九格抓來源。永久卡不可下載為普通格式。
- 《卡片之書》及所有一般卡片自由拖曳／跨普通卡冊依舊適用；已締結但尚未永久認證的原法陣卡只能在 GBA 暫存格。
- 完全不更動 Amin Pocket GBA EmulatorJS／APK／manifest／Bridge／GEN2 私有知識。
- 圖書館既有 14 本公開書、公開資源、角色探索、書架位置、多圈環繞與讀卡介面均需通過回歸驗收。

## 實作檔案
- `living-library/live/permanent-cards.js`：本機唯一 BOOK 名錄、可核驗資格、不可逆交易、物理卡片暫存、原世界物件座標更新。
- `living-library/live/permanent-gba.js`：GBA 選單、三秒同意與進化階段、安全中斷。
- `living-library/live/permanent-build.js`：共同地面有效範圍、點放、網格、搖桿微調、旋轉。
- `living-library/live/object-craft.js`：舊編輯／回收／拖曳入口的永久身分保護；舊法陣卡物件化交易支援位置原子保存。
- `living-library/live/index.html`：Three.js 原法陣及投影、控制器、地面點選、回載、原卡長按、建造切換。
- `living-library/live/atlas-runtime.js`、`atlas-model.js`：GBA MENU 永久管理、進化進度、物理卡片儲存／提取。
- `living-library/live/compendium-card.js`、`card-creation.html`：同一卡面升級外觀與已認證卡唯讀。

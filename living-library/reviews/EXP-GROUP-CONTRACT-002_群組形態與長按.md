# 群組契約：唯一形態與任一成員長按

OWNER 要求：已綁定群組任一成員長按三秒，整組六芒星動畫／選取後確認卡片化；實體化後原卡消失，收回時同一原卡出現。短按保留原功能。此次不調整掃描器與 GBA 編輯入口。

## 身分與互斥

沿用 scanContract.form、原 card.id 與既有 member kind/id。world 時隱藏原卡及其點選目標，card 時隱藏所有成員。底層原卡保存以供還原，不新增卡片。重載仍依契約重建互斥形態。整組使用唯一 boundCardId 場景錨點，沿用既有解除契約流程。

## 互動

對真實可見網格做射線點選，避免穿過前方物件選到後方成員。任一成員長按三秒，以整組包圍範圍顯示既有六芒星並標示所有成員；確認後全部收回原卡。取消、移動、失焦不寫入，確認前重查原卡 revision。此動作讀既有綁定，不依賴重新掃描。

短按轉交原物件的既有點擊行為。長按完成後不另觸發短按。原卡實體化與群組收回沿用原動畫及原子儲存。

## 驗證方法

340 項 Node 測試通過；原真實之眼六芒星幾何與三秒順序測試通過。scan-bundle.cjs 使用實際主頁、Three.js 與滑鼠指標，隔離合成存檔，覆蓋書本及整座圖書館群組、取消、短按、長按、同卡實體化／收回及既有解除契約。軟體 GPU 策略僅在測試攔截回應中放行，不能據此宣稱手機 GPU／WebView 驗收。

發布須以同一候選 CI、Pages 部署及實際 HTTP 來源驗證各自成立；OWNER 手機驗收仍待使用者操作。公開文件不含私人知識庫或真實存檔。此經驗文件可另行匯入檔案庫。

## 1. 目標、定義與絕對邊界

使用現有世界原點的地面法陣（顯示名稱暫定「初始法陣」）與玩家已建立且取好名字的「普通卡」實作首例。**完成綁定不等於完成永久認證；完成法陣卡片化也不自動等於 L2。**

- 「法陣」：場景中可選取的世界來源物件，具有穩定的來源 ID、名稱及世界座標錨點。來源 ID 初稿：local.world.sigil.initial；不是跨裝置的永久識別號。
- 「普通卡」：現有 ObjectCraft 的 local.card.* 資料，沿用原卡 ID、圖片、名稱、修訂號。
- 「候選印記」：第一次長按後，指示就近匹配的視覺預覽；在使用者按「是」完成契約前，不視為不可逆綁定。
- 「契約」：將同一張普通卡與一個法陣來源建立一對一關係，不複製卡片，不發放 L2 / 永久收藏編號。
- 「卡片化」：第二次長按已契約的法陣後，依使用者確認將來源的顯示形態從世界法陣切換為同一張實體卡。**不是創建第二張新卡。**
- 「升級」：L2 為後續獨立審核節點，需要對象驗證、AI 審查、OWNER 核准與正式唯一性登錄；本規格的任何儀式動畫不得偽稱 L2 已核准。
- 「互相兌換」：後續支援卡片 → 世界來源的逆向切換，始終沿用同一組來源/卡片綁定並還原原始錨點，禁止雙重實體。

**資料單一真相（必須遵守）：** 同一對契約在任何時間只能顯示一種實體形態；正常狀態不能同時存在「實體世界法陣」及「實體契約卡」。在轉換動畫中可以同時顯示視覺特效，但所有互動命中與資料操作必須先鎖定，不能被當成兩個可複製物件。

## 3. 玩家操作與每步明確條件

### 3.1 第一次長按：選取法陣及預覽最近卡（未寫入正式契約）

1. 玩家以滑鼠、觸控或筆直接命中**法陣專用命中區**，持續按住滿 3,000 ms。
2. 長按開始：外圈逐漸點亮，紋路緩慢旋轉，環形進度 0–100%；所有旋轉、拖曳、人物行走不得搶走此指標操作。
3. 提前放開、移出觸控容差、第二指加入、pointercancel、lostpointercapture、視窗失焦或頁面隱藏：立即取消；不選牌、不綁定、不修改存檔。
4. 3 秒真正達成時才觸發一次選取成功的脈衝；快照當下法陣與所有有效卡片的**世界座標**，由近到遠排序。先以三維距離上限 3.6 世界單位作為**候選參數**，待實測調整；相同距離用穩定 card.id 排序，不可不確定選取。
5. 候選卡條件：已命名、普通卡、可見、未回收、不在書內、不在移動/召喚/回收動畫中、沒有其它法陣有效契約，且距離在範圍內。若無候選則停止並顯示短提示。
6. 最近候選卡投射暫時符印、短光線與輕微回應；出現確認視窗：「是否施行『法陣卡片化之術』？法陣：初始法陣／媒介卡：〔原卡名〕」。名稱均從有效來源資料取得，**不硬寫死 UI 範例**。
7. 按「否」：解除預覽符印，法陣回待機，沒有副作用；按「是」：先重新校驗 card.id、source.id、版本、距離/可見狀態及未被其他契約佔用，再進入契約交易。

### 3.2 契約儀式：卡片飛入法陣並消失

- 0.00–0.55 s：地面符文由外向內亮起；卡面印記與法陣呼應。
- 0.55–1.30 s：卡片保持原身分與圖片，轉向法陣；光絲從印記接至法陣中心。
- 1.30–2.50 s：卡片沿世界空間曲線飛向法陣中心，縮小並伴隨細粒子。移動對象為**同一實體卡渲染模型**，不得新增「複製卡」。
- 2.50–3.10 s：卡片完全融入法陣；法陣中心形成契約封印；卡片不再出現在人物軌道、卡冊或另一個互動命中區。
- 完成後狀態：rune=sealed，card=embedded，contract=active；原始 card.id、圖片、名稱與來源法陣世界錨點保留。使用者需能看到封印後的法陣回應。
- 若交易寫入、分頁或 WebGL 中斷：不能只刪渲染物件就視為完成。先落地可恢復的交易意圖，動畫完成再提交顯示態；重新載入時依持久狀態決定重播、恢復或安全中止。

### 3.3 第二次長按：封印法陣轉成同一張卡

1. 玩家再次長按**已封印法陣**滿 3 秒；選取特效與首次相同，但辨識來源狀態 sealed，不再重新搜尋最近卡。
2. 彈出名稱帶入的確認視窗：「是否將『初始法陣』變成卡片？」；此時確認的對象是已綁定的 source.id 與原 card.id。
3. 按「否」保持 sealed。按「是」再次核對一對一契約、保存的錨點、版本與卡片不可同時在其他形態活動，才執行卡片化。
4. 動畫：法陣封印脈動 → 符紋收縮至中心 → 同一張契約卡由法陣中升起 → 轉向人物 → 沿曲線移入玩家漂浮卡軌道。
5. 完成後 rune=world_hidden，card=world_card，contract=active。**地面基座可保留作為世界場景的一部分，但法陣專屬發光符紋與互動實體不再存在**；不得有一個可操作的法陣與同一張卡同時存在。
6. 此張卡進入「已完成法陣卡片化／尚待 L2 審核」狀態，不立即變成正式 L2，也不配永久編號。其高階 3D 外觀可在審查模式預覽，不可冒充已認證的外觀資格。

### 3.4 逆向兌換（接口先設計，暫不直接啟用）

使用者從已卡片化且具有效錨點的契約卡提出「還原為法陣」要求，確認後鎖定來源及卡片，以同一交易進行反向動畫；將法陣**原位**恢復到保存的 position/quaternion/scale，卡片在世界顯示消失但記錄繼續存在。還原不是複製，也不使契約解除。第一版僅提供純狀態接口與驗收準則，**不在未核准的遊戲 UI 添加新按鈕**。

## 4. 狀態機（以契約對為資料單位，而不是兩套彼此獨立的旗標）

| 唯一狀態 | 法陣可互動 | 卡片可互動 | 主要事件 | 持久化 |
| --- | --- | --- | --- | --- |
| available | 可長按 | 仍在普通卡軌道 | HOLD_3000 → preview | 是，現有紀錄 |
| preview | 已選取待確認 | 有暫時印記 | CONFIRM / CANCEL | 否，僅記憶體 |
| sealing | 鎖定，特效進行 | 鎖定並飛入 | SEAL_COMMIT / RECOVER | 是，交易意圖 |
| sealed | 可再次長按 | 不可見，保存同一 card.id | HOLD_3000 → prompt | 是，契約 |
| cardifying | 鎖定，轉換中 | 受控升起 | CARDIFY_COMMIT / RECOVER | 是，交易意圖 |
| card_active | 不可作為互動法陣 | 同一張卡在軌道 | REQUEST_L2 / RESTORE_WORLD（後續） | 是，契約 |
| restoring | 鎖定，逆向動畫 | 鎖定 | RESTORE_COMMIT / RECOVER | 是，交易意圖 |
| world_active | 同一來源法陣恢復於錨點 | 卡片仍在資料庫但不可見 | HOLD_3000 或依設計再卡片化 | 是，契約 |

**不變量 I1：** 全系統同一時間 cardId ↔ sourceId 至多各綁一個。I2：有效形態只能是 world 或 card 其一。I3：卡片 ID、來源 ID、圖片、名稱不因動畫而被重新生成。I4：任何失敗都不能留下同時可操作的雙重實體。I5：動畫結束不是授權證明；L2 一律獨立驗收。I6：候選/印記不能代表已正式配發編號。I7：角色移動與法陣固定原點的座標不得互相誤用。

## 5. 候選資料 Schema（概念定義，非現有程式已實作）

- ritualId：一次儀式的冪等 ID，防止連點與刷新重放重複生成。
- sourceId、sourceName、sourceRevision：穩定來源與版本。
- sourceAnchor：場景識別、position、quaternion、scale；寫入時封存，不依照當下角色的位置還原。
- cardId、cardRevision：原普通卡的 local.card.*，不產生新卡 ID。
- contractState：available / sealing / sealed / cardifying / card_active / restoring / world_active。
- activeForm：world / embedded / card（衍生展示，不存彼此矛盾旗標）。
- bindingMark：候選時為暫時 overlay，契約後為與 sourceId 相關的持久印記 metadata。
- transaction：phase、expectedRevision、startedAt、committedAt、recoveryPolicy、eventId。
- l2Review：not_requested / pending / rejected / approved（本輪不得寫 approved）。
- permanentIndex：null（本輪始終 null）。

**保存規則：** 優先沿用 ObjectCraft 的單一原子資料快照更新策略，避免跨多個 localStorage key 分開更新而產生一邊已消失、一邊仍可互動的假成功。首次上線需可遷移與備份還原；既有 v1 不可直接覆寫或破壞。localStorage 單機僅能保證本機原型一致性，不能宣稱跨裝置唯一性。

## 6. 失敗／中止條件

- 未命中正確法陣、按住少於 3 秒、操作移動超容差（建議 12px，可在行動裝置驗收後調整）、第二指加入、拖曳已開始、頁面失焦。
- 附近無合法卡、距離超過候選半徑、候選卡未命名、來源或卡片正處於另一個儀式、法陣已有其他契約。
- 使用者取消、選取之後資料修訂改變、契約 ID 不一致、錨點遺失、localStorage 讀寫失敗、重整恢復中的不確定狀態。
- 任何前置驗證失敗應顯示具體原因，不修改卡片，也不強迫卡片移動。
- 低效能 / reduced-motion 應保留完整互動和交易驗證；只能縮短視覺效果，不能略過三秒及人工確認。

## 7. 一次完整人工驗收標準

- 在原點長按法陣 2.9 秒離開：不發生任何綁定；再次完整長按 3 秒才出現最近的已命名普通卡與印記預覽。
- 「否」不更動來源/卡片；「是」後原普通卡沿軌跡進入法陣並消失，在資料中仍保留原 card.id。
- 再長按封印法陣 3 秒，看到「是否將初始法陣變成卡片」；「是」後同一張卡飛出來漂浮，不重複一張。
- 此時不能再選到原地的活躍法陣；重整後仍只看得到一種形態。
- 不出現新永久編號，也不出現「L2 已完成認證」假訊息。

## 8. 仍需 OWNER 審核的設計點

1. 名詞是否最終採「法陣卡片化之術」；此版僅作候選顯示文案。
2. 來源真實名稱暫以「初始法陣」示意；必須對照遊戲現有命名來源，不自行修改原卡標題。
3. 3.6 世界單位是否為合適的最近卡搜尋半徑；在既有卡牌軌道與人物移動的實機體驗中核對。
4. 高階 3D 立體卡外觀是否在「已契約但未 L2」時預覽，或只能 L2 核准後正式使用。
5. 卡片 → 法陣的逆向入口與操作方式，以及如何區分場景底座和唯一來源法陣的形態。
6. 待本機首例可重現後，才討論跨裝置唯一權威與永久編號。

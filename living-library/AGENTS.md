# Living Library｜強制功能保留與版本回歸規則

適用於 `living-library/**`、與 Living Library 有關的 `packagecanvas/**` 及相應測試。Work／Codex／其他 Agent 每次修改前必須讀取本檔，以及 repository 根目錄 `AGENTS.md`。本檔只管理 Living Library UI／投影，不變更私有 GEN2 的治理規則。

## 不可違反的產品契約

1. **舊功能不能被資料來源更換所刪除。** 新增 GEN2 自動投影是「疊加」，不是「取代」既有的公開功能書、研究入口、操作入口或書內閱讀器。不得用「沒有示範書」作測試目標而移除已可用功能。
2. **無私有授權仍須能使用公開功能。** 未連線、授權失敗、斷線及離線時，必須留有安全的公開功能書與入口。私有 GEN2 內容必須清除，不能因為保留公開書而留下私人文字、ID 或 Token。
3. **來源與身分分離。** `gen2-knowledge/main/kb/` 仍是正式 GEN2 KB、Skill、Workflow 的正本；只顯示通過既有登記／Contract／候選篩選的正式投影，沿用真實 `kb_id`／`skill_id`／`workflow_id`。公開工作頁與候選研究卡是「功能／參考卡」，絕不可冒充正式 GEN2 Skill。每個實際入口有一個穩定 ID，可被多書引用而不複製身份。
4. **書本身分合併，不出現平行複本。** 《創業之書》可同時承載「公司設立任務」「創業技術研究卡」以及授權後的 `KB-STARTUP` Skill／Workflow。公開書本與正式 KB 投影映射至同一個閱讀容器；保留所有功能，但不得宣稱未經審核的內容已正式化。
5. **保留遊戲化操作閉環。** 3D 世界 → 選書／召喚 → 魔法圖鑑 → 卡片 → 書框內可上下捲動的功能 UI／MD → 返回圖鑑／關閉書本；沒有 WebGL 的裝置也須有 2D 可用入口。不得在一般同站工作頁無故整頁導航；禁止 iframe 的第三方網站須提供清楚外開備援。
6. **七個已存在的公開功能是回歸基線。** `public-capabilities.json` 列明精確身分、URL 與主要歸屬；至少其中四個 `requiredWithoutGen2` 無 GEN2 授權必須可達。研究導航、PackageCanvas、公司設立任務、Google 日曆、知識世界、GBA、Pocket Vault 均不得默默遺失。先前 12 本公用／示範書的視覺殼若有變動，須列出每本在新版本的入口或去向，且不能把展示書冒充正式 GEN2 KB。
7. **禁止重複實作後端。** 重用 `packagecanvas/gen2-source.js`，不另建正式卡片庫、不把私有 MD 放公開 repo、不額外放寬 Android Bridge。GitHub 負責儲存和 PR 審核，ChatGPT／Work／現有 Agent 依授權讀取、執行；網站不自行代替 OWNER 核准。
8. **現有可用能力以實測證據為準。** 新增功能不代表原功能可以移除。修改時先列舊／新功能對照，缺失標 FAIL，先修復再請 OWNER 驗收；不能只靠 Markdown 說明或 parser 測試宣告成功。
9. **環繞與書架必須是 3D 真實位置。** 不設死板七本上限；環繞書隨數量分多圈、不同高度。按「歸還書架」時移動同一本互動書模型至指定架位並可再次點擊召喚，不能只隱藏模型或把書轉移至底部 DOM 清單。保留不支援 WebGL 的 2D 書籍操作入口；偏好減少動態效果時，立即落位而不播放飛行動畫。書本 ID 和卡片來源不因搬動改變。

## 每次變更的固定驗收

- 開發前：讀取前一個已驗證版本與當前分支，核對 `public-capabilities.json` 和來源連結；列出 **保留／新增／刪改**。
- 自動測試：必須包含 **多圈環繞、3D 書架實體落位／可點擊召喚、減少動態效果時立即落位**、**未授權公開入口**、**已授權 GEN2 疊加**、**斷線清除私有而保留公開**、**創業之書三類卡同時存在**、**同站書內捲動和返回**、**同功能跨書不重複身份**。
- 驗收：每個基線入口可以實際點到，不只測試 HTML 中出現 URL；手機／WebView／網頁授權不能實測就標 `NOT TESTED`。
- 若保留功能的測試失敗、被刪除或尚未實測，維持 **Draft PR / 未完成**，不得合併 `main`、不得宣稱新版已全面取代舊版。
- 新進 Agent 不得因測試名稱、過時草案、重命名「示範書」就抹掉正式可用入口。**優先處理可用功能回歸，後做 UI 美化及新投影。**

## 來源權責

本檔與 `public-capabilities.json` 是 Living Library 候選版的功能保護契約，並非私有 GEN2 受控 Markdown 類型；正式 GEN2 的安全、審核、Skill 建立仍以 `gen2-knowledge/AGENTS.md` 和 `main/kb/` 為準。

## 操作流程
1. 打開 3D 圖書館，點書或從書庫清單選一本到技能書。
2. 展開書頁 → 從「書中的功能」按鈕前往原有頁面。
3. 使用瀏覽器或 Android 返回鍵回圖書館。
4. 若要改變環繞的書本，選「歸還書架／召喚到身邊」。
